# HAN Campus App

Lokale startweek-app in de stijl van de campus-mockup.

## Starten

Node.js en npm zijn nodig. Daarna in deze map:

```bash
npm install
npm run watch
```

De site draait op [http://localhost:5173](http://localhost:5173). Bij elke opslag herlaadt de browser automatisch.
